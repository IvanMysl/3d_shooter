# NEON RIFT 3D — Stage41 / MP-9: отладка сетевой сигнализации и мобильного HUD

Дата: 17.11.2026. База — Stage40/V40, отдельная копия исходников. Версия V41.

## Исправления

1. Мобильная альбомная раскладка: «ПОЛЁТ», «↑», «↓» перемещены из-под радара в ряд непосредственно над блоком действий. CSS привязан к нижнему краю экрана и safe-area; для высоты экрана до 340 CSS-px есть компактная раскладка. Положение взято как **приближение** по ручной разметке на присланном снимке. Точные пропорции и отсутствие пересечений на конкретном Android нуждаются в визуальном подтверждении.
2. Разрыв Metered WebSocket больше не завершает текущий матч, **если** жив хотя бы один прямой RTC DataChannel. Отдельное событие `presence.left` не удаляет удалённого бойца при живом игровом P2P-канале. Если P2P не работает, действует прежняя обработка отключения. Расчёт урона остаётся у ведущего.
3. Кнопка переподключения не выполняет запросы при недоступной сигнализации. Не подтверждённые сервером автоматические повторы освобождают квоту после восьмисекундной паузы. Повторные запросы в одной секунде ограничены как прежде.
4. Устранено молчаливое резервирование места игрока при отказе сервера подтвердить `join-accepted`: резервирование отменяется, состав обновляется и пользователь получает сообщение. Список участников публикуется с одной ограниченной повторной попыткой и видимой ошибкой, если Metered не подтверждает публикацию.
5. Сохранения одиночной кампании не изменяются, схема JSON и `MP_VERSION=2` сохранены.

## Проверки и ограничения

- Автотест `tests/test_stage41_mp9_signal_mobile.cjs`: 25 проверок на симулированных браузерах. Включает отключение WebSocket ведущего и гостя в середине матча, приём снимков после обрыва обеих сигнализаций, запрет запросов WebRTC без Metered, откат JOIN и неудачные автоматические ICE-повторы.
- Все ранее существовавшие тесты сохраняются и запускаются через `python tools/package.py`. Результаты конкретного выполнения нужно смотреть в итоговом журнале.
- Не проверено: реальное устройство Android, расположение кнопок при всех системных масштабах, реальная маршрутизация Metered/TURN, защита публичных комнат и долгие матчи из восьми устройств. Отключение сигнализации не равно полноценному восстановлению комнаты: после потери всех P2P-каналов требуется новый сеанс.
- Публичный `pk_live_` в проект **не добавлялся**. Никогда не встраивать `sk_`.
