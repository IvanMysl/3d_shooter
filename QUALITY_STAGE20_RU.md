# Этап 20 — переназначение E / Shift / Space

## Действующее управление ПК

| Клавиша | Действие |
| --- | --- |
| **E** | Фазовый рывок (телепортация по горизонтали, в том числе в полёте). |
| **Shift** (слева или справа) | Снижение высоты в режиме полёта. На земле не выполняет рывок. |
| **Space** | Набор высоты в полёте; обычный и повторный прыжок на земле. |
| **C** | Энергетический барьер (ранее E). |
| **Ctrl** | Дополнительная возможность снижения высоты, сохранена для совместимости. |
| **V / двойной Space** | Включение и выключение полёта при экипировке подходящего костюма. |
| **Q / F** | Импульс / лечение — без изменений. |
| **↑ / ↓** | Регулировка дальности рывка шагом 0,5 м — без изменений. |

Space+Shift одновременно удерживают текущую высоту. Переназначение не затрагивает сенсорные кнопки: «РЫВОК», «БАРЬЕР», набор и снижение высоты остаются самостоятельными действиями. Механика костюмов, их защита, стоимость способностей, дальность рывка и сохранения не менялись.

## Автоматическая проверка

- `tests/test_stage20_keybindings_flight.cjs`: исходный обработчик клавиатуры проверяется отдельно от полного браузера; проверяются назначения E, C, Q, F, отсутствие рывка на Shift, клавишные удержания, сохранение сенсорных кнопок. Используется настоящий вертикальный расчёт физики на первом секторе: Space вверх, оба Shift вниз, Ctrl вниз, две сенсорные команды, одновременное Space+Shift.
- `tools/package.py`: включает прежние Stage 1–19 регрессии, структурные проверки сборки, SHA-256 и ZIP-целостность.

В этой среде Chromium не может стартовать из-за системного ограничения сокетов. Поэтому визуальную и пользовательскую проверку на ПК/телефоне необходимо выполнить вручную; сценарии приведены в `FINAL_TEST_GUIDE_RU.md`.
