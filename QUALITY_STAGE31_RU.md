# Контроль качества — Stage31: карта и награды между уровнями

## Исправлено

- Если уровень 3 пройден, уровень 4 открыт, но награда ещё не выбрана, кнопки карты показывают **сначала получение награды за уровень 3**, затем запуск уровня 4.
- Экран выбора улучшения объясняет, что нужно выбрать **одну карточку из трёх**; после выбора автоматически начинается следующий сектор.
- Открытие нового экрана сбрасывает прокрутку к началу, чтобы на телефоне больше не возникал экран награды «без заголовка». Перерисовка *того же* меню паузы сохраняет прокрутку.
- Сохранение незабранной награды, применение выбранного улучшения, переход в следующий сектор и возобновление уже начатого уровня используют прежний механизм, без изменения баланса.

## Автоматическая регрессия

`node tests/test_stage31_pending_reward_navigation.cjs` — **22 проверки**:

1. Подписи обоих переходов с уровня 3 на уровень 4 при сохранённой незабранной награде.
2. Восстановление существующей контрольной точки, а не запуск новой игры.
3. Обычное возобновление уже начатого уровня 4 и отдельный запуск нового уровня 4.
4. Переход к началу экрана после открытия нового окна без нарушения переключения полноэкранного режима.
5. Восстановление конкретного набора наград, применение выбранного улучшения, запуск и сохранение уровня 4.

Все прочие регрессионные тесты запускает `python tools/package.py --output ...`. Тесты HTML/JavaScript не заменяют ручную проверку реального Android-устройства: шаги приведены в `FINAL_TEST_GUIDE_RU.md`.
