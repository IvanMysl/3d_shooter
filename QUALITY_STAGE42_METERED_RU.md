# NEON RIFT 3D — Stage42: публичный ключ Metered встроен

Дата: 17.11.2026. Основа — полная Stage41 / MP-9, без изменений сетевого протокола, физики и сохранений.

- Пользователь предоставил на скриншоте publishable key с префиксом `pk_live_`, статусом **Active**, разрешениями **subscribe/publish/presence/send**, и переключателем TURN **On**. Это сведения dashboard, а **не** результат сетевого подключения из самой игры.
- Ключ установлен в `src/21b-multiplayer-lobby.js` и попадает в автономный `index.html` при сборке. Это публичный ключ и он доступен посетителям сайта. Секретный `sk_...` никуда не добавлялся.
- Обновлена видимая версия до V42, чтобы публикация по `?v=42` не смешивалась с уже посещавшимся `?v=41`. Совместимость протокола сохранена (`MP_VERSION=2`). Для тестов применяется исключительно подставной публичный ключ в локальных WebSocket-имитациях.
- Перепаковка и тесты выполняются штатной командой `python tools/package.py`. Новая проверка `tests/test_stage42_metered_config.cjs` сравнивает настройку в исходнике, собранном скрипте и `index.html` и не печатает сам ключ.

## Что НЕ проверено

Доступность Metered в интернете, действительная WebSocket-аутентификация, TURN-квота, соединение WebRTC между двумя настоящими устройствами, расположение сенсорных кнопок на Android, и работа комнаты с восемью пользователями. Статус Active в dashboard не гарантирует этих результатов.

## Что делать

1. Сохранить резервную копию своего игрового прогресса через JSON-экспорт.
2. Разместить **новый** `index.html` из Stage42 в корне GitHub Pages репозитория; дождаться завершения публикации.
3. Открыть `https://ivanmysl.github.io/3d_shooter/?v=42` и проверить, что показана **V42** и больше не выводится сообщение о ненастроенном публичном ключе.
4. Создать комнату и подключиться со второго устройства, предпочтительно из другой сети. Зафиксировать текст первой ошибки либо результат `P2P ✓`. Публичный ключ **не нужно присылать повторно**, а секретный нельзя присылать вообще.

**Важно:** обладатели публичного ключа могут использовать выданные ключу разрешения Metered, поэтому ограничьте каналы/квоты по возможности и следите за использованием бесплатного тарифа. Реальная защита комнаты от подмены ведущего не гарантирована браузерным publishable key.
