# NEON RIFT 3D — STAGE100: PHYSICAL EXTRACTION BOUNDARIES

**Дата:** 21 ноября 2026 года. **GAME_BUILD:** 100; **MP_VERSION:** 41 (сетевой протокол не изменён). **Общая приблизительная готовность:** 98,2% (Stage99 — 97,8%). Это экспертная оценка, не процент покрытия или гарантия отсутствия ошибок.

## Что обнаружено и исправлено

### 1. Физически некорректное завершение уровня

В предыдущей версии игра вызывала `portalNext()` при выполнении только горизонтального условия `distance(p, portal) < 1.18`. Игрок на другом этаже, а также игрок за настоящим низким металлическим заграждением могли завершить уровень, фактически не войдя в проход. Указатель маршрута уже учитывал физическую навигацию, но сам игровой переход обходил её.

`src/19-gameplay-update.js`: общая проверка `physicalPortalContact(p)` теперь требует: горизонтальная дистанция меньше 1,18 м; согласованность высоты ног с физическим полом входа (не более 1,80 м); отсутствие стены и пересечения настоящего 3D-объёма корпуса игрока; свободный 3D-луч к точке входа по общему `rayWall` и динамическим AABB оборудования. Игровой `update()` вызывает `portalNext()` только после этой проверки. Если портал рядом, но заблокирован этажом или металлом, HUD сообщает причину. Допуск конца физического луча — 2 мм, чтобы не игнорировать тонкий выступ у самого входа.

### 2. Тонкий металл у собираемого бонуса

Обнаружен отдельный граничный дефект Stage99: `worldLootPickupClear` игнорировал попадание луча в последние 15 мм перед бонусом, что позволяло «магнитить» предмет через физически твёрдую стальную пластину толщиной 5 мм непосредственно перед объектом. Исправлено в `src/04a-static-world-solids.js`: допуск сокращён до 2 мм. Тот же согласованный физический допуск установлен в `worldLootSpawn`; другие правила реального 3D-контакта, высоты моста, поддержка старых сохранений сохранены. Это не добавляет новых коллайдеров, стен или декораций.

### 3. Автоматический контроль

`src/27-main-loop-diagnostics.js` дополняет read-only проверками `__neonTest.physicalExtractionAudit()` и `__neonTest.physicalExtractionGameplay()` с временными тестовыми состояниями, которые восстанавливаются после проверки. Реальный игровой кадр проверяется с подменой только завершающего перехода, чтобы испытание не изменяло прогресс пользователя. Время кинематографической заставки временно отключается только внутри QA и затем восстанавливается.

## Физика препятствий и неизменность мира

Сохранены без модификаций все 100 карт, `mapCells`, `heightCells`, статические физические AABB, генератор уровней, меши, лестницы, мосты, стены и WebGL/Canvas визуализация. `src/04-map-generation.js`, `03-height-and-collision.js`, `05-world-mesh.js`, `11-fallback-render.js`, `14-combat-raycast.js`, модули NPC-навигации и PvP байтово совпадают со Stage99. Уточнён только физический контакт с *существующими* объектами. **Ни одного нового видимого объекта без коллайдера и ни одной новой невидимой стены.**

## Ограничения

- Автоматический браузерный тест выполнялся в Chromium с **Canvas fallback**, а не на реальной аппаратной видеокарте WebGL. Требуется аппаратный тест на ПК и Android с профилированием FPS.
- Не выполнены длительное ручное прохождение всех 100 уровней и PvP между двумя физическими устройствами.
- Полный старый монолитный `tools/package.py main()` не завершён; архив допускается собирать штатными `included/make_sums/make_zip` после перечисленных адресных и регрессионных проверок.
- Оценка 98,2% **не является гарантией отсутствия ошибок**; номер Stage100 — номер итерации, а не показатель 100% завершения.

## Как проверить самостоятельно

```sh
python tools/build.py
python tools/build.py --check
node tests/test_stage100_physical_portal_contact.cjs
node tests/test_stage100_precision_loot_contact.cjs
# Блоками реальных карт (пример для Linux/macOS):
LEVELS=1,2,3,4,5 node tests/test_stage100_real_physical_extraction.cjs
python tests/browser_stage100_physical_extraction.py
python tests/browser_stage99_physical_loot.py
python tests/browser_smoke.py
```

На Windows PowerShell вместо `LEVELS=...` задавайте `$env:LEVELS='1,2,3,4,5'`. Во время ручной игры проверьте, что портал завершает уровень только при физическом входе, но не с другого этажа или через металлическое ограждение. Сравните сбор бонуса через тонкую реальную стальную перегородку с открытым сбором рядом.
